# Outra Volta

Portal de anúncios de iPhones em segunda mão, com área reservada. Página única, em HTML, CSS e JavaScript, sem dependências nem passo de compilação. Segue o Material Design 3.

## O que inclui

- Página inicial com pesquisa rápida (nome do anúncio, estado, preço mínimo e máximo) e filtros avançados (localização, modelo, armazenamento, bateria, desbloqueado, garantia).
- Megamenu "Explorar", por estado e por modelo.
- Página de resultados com filtros ativos, ordenação e estado vazio.
- Página de anúncio, guardados, os meus anúncios, vender (com pré-visualização) e ajuda.
- Perfil público dos vendedores, com os anúncios ativos de cada um.
- Mensagens para quem tem sessão iniciada (lista de conversas, histórico e resposta).
- Autenticação de demonstração, tema claro e escuro.

## Como usar

Abra o `index.html` num browser.

## Estado atual

Projeto de demonstração. Os 18 anúncios são dados de exemplo. O login aceita qualquer email com uma palavra-passe de 6 ou mais caracteres. Sessão, guardados e tema ficam no `localStorage`, e os anúncios novos só existem durante a visita. Para uso real é preciso um backend (contas, anúncios, mensagens e fotografias).
